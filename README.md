# Gift Shopping Website

A static front-end gift shopping website built with HTML and CSS.

## Project Structure

```
Gift-Shopping-Website/
├── Landing/          # Home / landing page
├── Categories/       # Browse gift categories
├── Products/         # Product listing pages
├── Shop_Now/         # Shopping / checkout flow
├── Offers/           # Deals and promotions page
├── Contact_Us/       # Contact form page
├── logo.png          # Site logo
└── delivery.jpg      # Delivery banner image
```

## Pages

- **Landing** – Entry point of the site; introduces the brand and navigation.
- **Categories** – Displays available gift categories for browsing.
- **Products** – Lists individual products within each category.
- **Shop Now** – The main shopping/purchase flow page.
- **Offers** – Highlights current deals and discounts.
- **Contact Us** – Contact form for customer inquiries.

## Technologies

- HTML5
- CSS3

## Getting Started

No build tools or dependencies required — it's pure HTML/CSS.

1. Clone the repository:
   ```bash
   git clone https://github.com/KD7789/Gift-Shopping-Website.git
   ```
2. Open any `*.html` file inside the relevant folder directly in your browser (e.g., `Landing/index.html`).
